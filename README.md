# 365 Tage wir

Eine mobile Liebesgeschichte für Gessica zum ersten Jahrestag.

## Bilder ersetzen

Die sieben Platzhalter liegen unter `assets/1.jpg` bis `assets/7.jpg`. Ersetze einfach die jeweilige Datei und behalte den Dateinamen bei. Am schönsten wirken hochformatige Bilder; die Seite schneidet sie auf Mobilgeräten automatisch passend zu.

## Veröffentlichung

Die Seite ist statisch und kann direkt über GitHub Pages oder Cloudflare Pages veröffentlicht werden. Einstiegspunkt ist `index.html`.
